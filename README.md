# Hey, I'm Kaike Cesar 👋

**Fullstack Developer | IIoT & Cloud**

I build industrial monitoring systems that process real-time telemetry from thousands of assets. Currently working with heavy industry clients like **Vale**, **ArcelorMittal**, and **Suzano** — delivering both serverless and serverfull architectures at scale.

## What I do

**Serverless** — Event-driven IIoT pipelines processing telemetry from 5,000+ assets via LoRaWAN, built on AWS Lambda, IoT Core, and DynamoDB. Infrastructure as Code with CloudFormation, observability with CloudWatch.

**Serverfull** — Real-time equipment monitoring platforms handling 490+ data tags every 5 seconds per asset. MQTT ingestion, WebSocket streaming, high-density dashboards with AmCharts5 for field diagnostics. Designed room-per-equipment WebSocket architecture to solve multi-user concurrency issues.

**Migrations & Integrations** — Led Cassandra → TimescaleDB migration eliminating query bottlenecks. Developed critical B2B integrations automating real-time alarm transmission for large-scale monitoring contracts.
